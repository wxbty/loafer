Loafer 多 Agent 软件交付平台

在软件研发中，从自然语言需求到可访问生产服务仍依赖大量人工协同，AI 工具多停留在单点代码补全，难以完成“需求→计划→编码→测试→部署→验证”的端到端闭环。Loafer 以 AgentTeams（HiClaw）Manager-Worker 多 Agent 协同范式为设计基点，构建全自动软件交付平台：计划生成、任务分解、开发、测试设计、测试执行、自动修复、部署验证、基础架构校验 8 个职能 Agent 按依赖编排执行；通过结构化状态机、JSON 结果契约、统一工具网关与持久化执行证据实现上下文传递与协同。每个 Agent 能力以标准化 Skill 契约沉淀（已落地为注册表与 API），外部工具通过等价 MCP 契约接入，支持后续平滑迁移。核心创新是业务模块质量门禁：任务完成后自动部署，测试 Agent 生成并执行 API + Playwright UI 用例，失败由修复 Agent 自动修复（最多 3 轮），全程无需人工暂停，并支持断点续跑与人工兜底。项目采用 Go + Vue3 实现，已完成多个 Demo 端到端交付，计划逐步开源为可复用的软件研发 Agent Infra。
